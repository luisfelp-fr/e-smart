# Versões FIXAS de propósito.

# Dois motivos:
#
# 1. Segurança. openpyxl, xlrd e odfpy leem bytes que qualquer pessoa envia
#    pelo upload, e é onde as vulnerabilidades desta pilha aparecem. Com
#    ">=" o ambiente instalava o que estivesse disponível no dia do deploy,
#    e ninguém sabia qual versão estava rodando quando saísse um CVE.
# 2. Reprodutibilidade. O relatório carimba a versão do algoritmo (commit),
#    o que só reproduz o resultado se as bibliotecas também forem as mesmas.
#
# Pino sem atualização vira dívida: .github/dependabot.yml abre PR semanal
# com as versões novas, e aí atualizar é decisão consciente com CI para
# conferir, em vez de acontecer sozinho num deploy qualquer.
#
# Para atualizar e regravar este arquivo:
#     pip install -U -r requirements.txt && pip freeze > requirements.txt
# (revise o resultado: o freeze inclui dependências transitivas)
